# 一、简介
基于s3dweb-open开发的数孪万象项目。项目开源，用户可私有化部署。
用户使用浏览器访问系统，支持三维场景的在线设计工具。
支持多用户、权限管理，数据存储在服务器端。
开发语言：JavaScript、Java。

三维场景设计的核心代码，请关注[s3dweb-open](https://github.com/softsdu/s3dweb-open)
