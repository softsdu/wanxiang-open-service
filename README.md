# 一、简介
本项目中文名为“数孪·万象”，可用于三维场景的在线设计，例如文物、设备、建筑、家电等物品的三维虚拟展示。 
项目前端使用了[wanxiang-open-web](https://github.com/softsdu/wanxiang-open-web)。
项目还提供了后台管理功能，支持多用户、权限管理，数据存储在服务器端。
项目代码开源，用户可私有化部署。
开发语言：JavaScript、Java。

前端三维场景设计的核心代码为[wanxiang-open-web](https://github.com/softsdu/wanxiang-open-web)
